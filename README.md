# Инди · Солнечный храм · Мобильная версия

[Играть на телефоне](https://vasio.github.io/indi-mobile/)

Шесть глав пиксельного приключения. Поверни телефон горизонтально: кнут расположен слева, стрелки — справа. Веди палец между стрелками для диагонального движения и одновременно нажимай кнут другой рукой.

При повороте телефона и скрытии страницы игра встаёт на паузу. Прогресс сохраняется в браузере отдельно от компьютерной версии.

Игра полностью содержится в `index.html`: её можно скачать и открыть без интернета.
